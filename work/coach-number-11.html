Coach Number 11

An observation-horror puzzle on a train. Every coach looks the same, until one doesn't.

my role

The idea

You're trying to reach coach number 11. In each coach you look around carefully and decide: is this the same coach as the last one, or has something changed? Get it right and you move forward.

The concept came from Shinkansen 0 and The Exit 8, games where the scare comes from noticing something small is wrong, rather than from something jumping out at you. I set mine in an Indian railway sleeper coach.

What I built

  • Every 3D model in the game, made in Blender: the coaches, bunks, fittings and props
  • The level layout, and the same-or-changed loop: inspect a coach, make the call, move on
  • AI behaviour and the gameplay code in Unreal Engine
  • A playable Windows build on itch.io

The hardest part

The anomalies. I was designing them while I was building the game, so every new idea meant going back into code I'd already written. There was a lot of back and forth.

What I'd do differently

Design the full list of anomalies before writing any code. Knowing every change the game needs to make up front would let me build the systems for them once, and keep development smooth.

What's next

It's a prototype and I'm still working on it. Next up are new anomalies (defects), more features and more gameplay elements.

it's free on itch: go and see if you can spot the changes
